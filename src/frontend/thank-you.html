🙏 Thank You

This project would not have been possible without the people, teams, and open data sources listed below. Universe Data Booklet is built on top of their free, public work.

🛰️ Data & API Providers

NASA

  • NASA NEO Web API — Near-Earth Object close-approach data (api.nasa.gov/neo)
  • NASA DONKI — Solar storm / geomagnetic data
  • NASA InSight Mars Weather
  • NASA Solar System Treks — LRO WAC Mosaic (Moon) & Viking MDIM21 (Mars) tile rasters, served through the NASA/JPL Trek WMTS
  • NASA Exoplanet Archive (via IPAC) — confirmed exoplanet catalog
  • NASA/JPL Small-Body Database

NASA data is public domain. Attribution: "NASA/JPL-Caltech" where applicable.

USGS

  • USGS Earthquake Hazards Program — real-time earthquake feed (earthquake.usgs.gov). USGS data is public domain.

Open-Meteo

  • Open-Meteo — elevation & current-weather API. Licensed CC BY 4.0. Cite as: Open-Meteo (https://open-meteo.com).

Open Notify

  • Open Notify — live ISS position and "who is in space" endpoints. Open-source; see open-notify.org.

ESA / Copernicus

  • ESA / Copernicus DEM — elevation reference data used by the Planetary Explorer terrain comparisons.

Full Solar System encyclopedia data

The encyclopedia covers the Sun, Mercury, Venus, Earth, the Moon, Mars, Jupiter, Saturn, Uranus, Neptune, Pluto, Ceres, and 9 moons (Phobos, Deimos, Io, Europa, Ganymede, Callisto, Titan, Enceladus, Triton). Physical figures (mean diameter, mass, gravity, atmosphere, temperatures, orbits, satellite counts) are compiled from NASA/JPL-Caltech, USGS, ESA, and other public-domain sources and are suitable for educational use.

🐙 Source on GitHub

The source code for Universe Data Booklet (including the integrated Project Base — Planetary Explorer feature) is developed in the open and published on GitHub.

Universe Data Booklet
MDSUWasi / Universe-Data-Booklet
Interactive explorer for Near-Earth Asteroids, Exoplanets, and Planetary Terrain — with PDF export, 3D views, study mode, and the embedded Planetary Explorer research tool.
License: MIT
Backend: Python 3.13 (http.server)
Frontend: HTML5, CSS3, Vanilla JavaScript
Hosting: PythonAnywhere
View on GitHub Download ZIP

What's in the repository

  • src/frontend/ — Universe Data Booklet frontend (HTML, CSS, JS modules, bundled libraries)
  • src/frontend/js/pdf.js — Save-as-PDF report generation for asteroids & exoplanets
  • src/backend/ — Python backend server and API endpoints
  • src/data/ — Committed datasets (exoplanets CSV, asteroids JSON)
  • Project Base/ — Integrated Planetary Explorer feature (Leaflet, Three.js, GSAP)
  • docs/ — Terms, Privacy, methodology
  • DEPENDENCIES.md / THANK_YOU.md / CREDITS.md — attribution & licences
  • LICENSE — MIT License
  • README.md — setup & usage guide

Clone & run locally

git clone https://github.com/MDSUWasi/Universe-Data-Booklet.git
cd Universe-Data-Booklet
# requires Python 3.13+
python src/backend/server.py
# then open http://localhost:8081

See README.md for the full quick-start guide and prerequisites.

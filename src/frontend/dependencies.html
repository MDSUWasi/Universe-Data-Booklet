📦 Dependencies

This project bundles open-source libraries and relies on free public data feeds. Every JavaScript/CSS dependency is shipped offline under src/frontend/lib/ (Universe Data Booklet) and Project Base/frontend/lib/ (Planetary Explorer) so the apps work with no network connection after the first load.
